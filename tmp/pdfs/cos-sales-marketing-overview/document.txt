Document purpose and authority

This standalone overview defines the complete Sales & Marketing navigation shell: one global drawer, the approved 13-area menu order and one contextual
submenu state for each area.

Global state                                                                 Module state

Full 13-area drawer with entity scope, user identity and workspace context.  Collapsed global icon rail plus the selected area's contextual submenu.

Persistent context                                                           Render rule

Entity scope and the user's authorised route remain visible and retained.    One full-resolution plate per landscape page so every submenu remains legible.

Authority and boundaries

Rule                      Meaning

Supersedes                Earlier navigation-shell guidance, including the prior 248px single local rail.

Does not change           Functional requirements, data, roles, workflows, integrations or QA decisions in the ten Content & Social specifications.

Target-state status       The navigation hierarchy and visual language are approved; background data is illustrative and does not expand Launch scope.

Launch authority          Launch / Scale / Native end-state classification remains controlled by the ten detailed specification documents.

Navigation model and design system

Step          Action                                 Required behaviour

1             Open global menu                       Show the complete 13-area drawer, entity scope and signed-in identity.

2             Select an area                         Collapse the drawer to the icon rail and open the selected contextual submenu.

3             Select a route                         Open the route while keeping the global area, local route and entity scope unambiguous.

4             Dismiss navigation                     X, outside click or Escape restores the unchanged workspace and returns focus.

Shared interaction, access and responsive rules

Rule                  Required behaviour
Active state          Exactly one global area and one local route are unmistakably active.

Persistence           Entity scope and the last authorised route persist between navigation states and sessions.

Workspace protection  The visible workspace is non-interactive beneath the dim overlay; navigation never discards dirty work without warning.

Scrolling             Only the route list scrolls; module title, entity controls and local search remain available.

Permissions           Unauthorised routes are hidden by default; a disabled state is used only when an explanation is operationally useful.

Keyboard              Logical tab order, visible focus, Enter/Space activation and Escape dismissal; focus returns to the opener.

Mobile                Show one navigation layer at a time; a back control returns from the contextual submenu to the global menu.

Touch                 Maintain minimum 44px targets and adequate spacing between adjacent controls.

Labels                Do not abbreviate approved route names unless a separate approved display label is recorded.

Chevrons              Use only for genuine nested navigation, never as decoration on leaf routes.

Acceptance gate: The global menu must contain all 13 areas in the approved order, and the gallery must contain exactly 13 contextual submenu renders with
every approved route visible.

Render inventory

14 plates total: 1 global menu + 13 submenu states. The previously approved Global Main Menu and Creators & Partnerships renders are retained unchanged; twelve missing
submenu states complete the set.
